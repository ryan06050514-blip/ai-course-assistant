AI 課程問答助手

結合大型語言模型的本地 AI 學習工具

個人 AI 迷你專題｜GitHub Pages 展示

一、專題介紹

本專題製作一個 AI 課程問答助手，協助使用者理解 Python、人工智慧與程式設計相關概念。使用者輸入問題後，由大型語言模型產生回答，作為學習與複習的輔助工具。

專案使用 Python 建立後端服務，透過 Docker Compose 管理應用程式、資料庫與本地模型服務，並提供網頁操作介面。

二、主要功能

  • 以自然語言輸入課程問題。
  • 使用本地 Ollama 模型產生 AI 回答。
  • 支援串流回應，讓回答逐步顯示。
  • 提供不同學習模式，協助理解概念、閱讀範例與整理考試重點。
  • 提供網頁介面，方便提問與複習。

三、如何在本機執行

  1. 安裝 Docker Desktop，並確認 Docker 正常啟動。
  2. 將 GitHub 專案下載或複製到電腦。
  3. 依照專案的 README.md 與 .env.example 設定必要環境變數。
  4. 在專案根目錄開啟終端機，執行 docker compose up --build。
  5. 等待服務啟動後，使用瀏覽器開啟 http://localhost:8080。

首次啟動可能需要下載模型與相關映像檔，請預留足夠的磁碟空間與記憶體。

四、成果與測試

  • 已建立 AI 課程問答網頁。
  • 已在本機透過 Docker Compose 啟動服務。
  • 已確認本機 localhost:8080 可以正常取得 AI 回答。

注意：此 GitHub Pages 網頁是專題展示頁。AI 問答功能需要本機或另外部署的後端 API 與模型服務，因此不能直接在此靜態頁面使用。

五、AI 工具使用說明

開發過程中使用 ChatGPT 協助理解程式架構、調整系統提示詞、規劃前端學習模式、排查網頁與 API 連線問題，以及整理專題說明。

開發者自行修改與整合前後端程式，並在本機啟動 Docker 服務、測試提問流程及檢查 GitHub Actions 部署結果。AI 產生的建議仍須經過實際測試與確認。

六、技術與學習心得

本專題整合 Python、HTTP API、HTML、CSS、JavaScript、Docker Compose、Ollama、GitHub 與 GitHub Actions。開發過程讓我練習前後端串接、本地大型語言模型應用、版本控制與自動化部署。
