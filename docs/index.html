🚀 啟動真正的 AI 問答

  3. 依照 .env.example 和 README 說明準備環境設定。
  4. 在專案根目錄開啟終端機，執行 docker compose up --build。

📚 專題介紹

本專題是一個 AI 課程問答助手，協助使用者理解 Python、人工智慧與程式設計相關概念。使用者以自然語言提出問題，由大型語言模型產生回答，作為學習與複習的輔助工具。

專案使用 Python 建立後端 API，以網頁提供操作介面，並透過 Docker Compose 管理應用程式及本地模型服務。

✨ 主要功能與技術

  • 自然語言課程提問。
  • 使用本地 Ollama 模型產生回答。
  • 串流回應，讓回答逐步顯示。
  • 不同學習模式：概念解說、範例教學與考試重點。
  • 技術：Python、HTML、CSS、JavaScript、Docker Compose、Ollama、GitHub Actions。

🧪 測試成果

  • 已在本機透過 Docker Compose 啟動服務。
  • 已確認本機 http://localhost:8080 可以正常取得 AI 回答。
  • 已設定 GitHub Actions 部署此靜態專題展示頁。

本頁為專題說明用途；實際 AI 回答功能請在本機啟動後測試。

🛠️ AI 工具使用說明

開發過程中使用 ChatGPT 協助理解程式架構、調整提示詞、規劃學習模式、排查前後端 API 連線問題，以及整理專題文件。

開發者自行整合及修改程式，並在本機啟動 Docker 服務、測試問答流程和檢查部署結果。AI 提供的建議會經過實際測試與確認。
